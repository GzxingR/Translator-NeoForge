## Design references / 设计参考

This mod implements in-game translation features similar in spirit to the open-source **Translator** ecosystem. The NeoForge codebase was restructured independently; the following projects informed design and architecture:

| Reference | Link | Notes |
|-----------|------|-------|
| Translator (Fabric) | [Cfghtiu/Translator3](https://github.com/Cfghtiu/Translator3) | Original open-source mod concept |
| NeoForge MDK 1.21.1 | [NeoForgeMDKs/MDK-1.21.1-ModDevGradle](https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle) | Gradle / NeoForge scaffold |

## Third-party services

Translation backends (Baidu, Youdao, Tencent Cloud, Bing, OpenAI-compatible APIs) require **your own API keys**. This mod does not ship credentials.
