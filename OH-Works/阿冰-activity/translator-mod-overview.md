# Translator Mod — 巡检简报

**时间：** 2026-06-10 20:07
**项目：** Translator-1.21.1-neoforge

## 项目概览

这是一个 **NeoForge 1.21.1** 的客户端游戏内翻译 Mod，作者 Gstar。
功能包括：
- 自动翻译聊天、悬浮提示、标题、计分板、Boss 血条、告示牌、TextDisplay 浮空文字、实体名称
- 手动 `/translate` 和 `/translate-re` 命令
- OCR 屏幕翻译（按 O 键）
- 多后端支持：百度、有道、腾讯云、Bing、OpenAI 兼容 LLM
